A whole-line message test (DEC-030's precedent) is the right guard, and it buys exactly one thing: the rendered sentence cannot drift. It cannot buy truth, because the pin records whichever sentence someone chose. Two audits of smut's query surface found the same failure twice at different altitudes: a rule authored for one case, generalised by the code to a family, so the sentence asserts a cause it has never established.

Worked examples from SL-010 (all live findings, all one shape):

- `smut q 'url=a=b'` -> "a field name holding = is outside q's grammar". The field is `url`; the *value* holds the `=`. The design row was written for `a=b=c`; `dsl::ambiguous` applies it to every repeated-operator token.
- `smut q --from=` -> "a comma list is a list of names, and one is empty". `--from` is one id whose commas are its own text; the list sentence was borrowed because the flag arm needed one.
- A guide sentence copied faithfully from a design section ("the hot path therefore has no flags") arrived in a context where the section's own examples refute it four times within a screen. The design's surrounding examples did not travel with the sentence.

The check that catches this class, and it is a reading rather than a test: take each sentence's *subject* and ask whether the code can reach it with the subject different. Refusal text that names a cause ("a field name holding …", "contains no "=") is the highest-risk shape; text that names only what was typed is not.
